¿Quién valida la información?

Validación de interfaz (cliente)

  • Campos obligatorios completos
  • Formato de correo, teléfono, fechas
  • Archivos adjuntos permitidos

→ Formularios HTML + JS en Presentación

Validación de negocio (servidor)

  • Rol tiene permiso para la acción
  • Estado permite la transición
  • Coordinador solo su área
  • Tutor no auto-asigna casos

→ AuthService + ValidationRules + PermissionEngine

Validación académica (humana)

  • Docente revisa informes del tutor
  • Coordinador aprueba solicitudes
  • Director genera informe mensual
  • Empresa firma informe final

→ Flujo institucional del documento CITI

Validación de datos (BD)

  • Integridad referencial (FK)
  • Roles únicos por usuario
  • Estados válidos (ENUM)
  • Auditoría de cambios

→ Constraints en base de datos
