Prototipo interactivo — Flujos

Equivalente a la página "Flujos" en Figma. Cada flujo activa una barra de progreso y conecta pantallas con hotspots.

Flujo 1 — Login correcto por rol

Landing → Login → seleccionar rol → credenciales → Dashboard

Flujo 2 — Login incorrecto (aislamiento)

Portal Admin + credenciales Cliente → Error → redirect portal Cliente

Flujo 3 — Solicitud asesoría (CU-01)

Cliente solicita → Coord. aprueba/asigna → Tutor informe → Docente revisa → Cliente firma

Flujo 4 — Registro recepción

Consultor → registro consulta → tabla actualizada

Flujo 5 — Cerrar sesión

Dashboard → Logout → Login
